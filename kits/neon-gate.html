What the plugin looks like

What it does

80s drums with the gated snare already done. A big gated-reverb snare, punchy toms and shimmery cymbals, with no gate plugin to set up and no reverb to tweak. GATE sets how much gated reverb you hear. Turn it up and the hold gets shorter and tighter. Prefer it bone dry? Switch the variant to Raw and the gating is gone. Synth-rock, retro pop-metal, darkwave, anything that wants that snare. Load it and play. The mixer is optional.

Features

  • GATE knob: gated reverb amount. The hold gets tighter as you turn it up.
  • Kit variants Natural (gated kick/snare/toms envelopes) and Raw (ungated).
  • 5 presets (Default, Raw / dry, Tight, Roomy, Big and loud) and a Tune knob (±3 semitones on kick/snare/toms).
  • Six faders (Kick, Snare, Toms, Cymbals, Room, Master) and a MIDI map menu (GM, merged alternates, pedal hat, flipped toms).
  • VST3 + standalone for Windows. Groove player for your own MIDI files. Credits inside the plugin.

System requirements

  • OS: Windows 10 or 11, 64-bit (tested on Windows 10)
  • Host: A 64-bit VST3 host, or use the included standalone app. Tested in REAPER.
  • Disk: Download about 89 MB (LHL_Neon_Gate_1.0.0_Setup.exe)
  • Mac / Linux: Not available yet. Windows only for now.
  • Internet: Only to download. No activation.
